`anyr` writes compact JSON to stdout by default. Diagnostics and progress use
stderr, so commands compose with `jq` and other tools. Use `--pretty` for
readable JSON or `--table` for terminal output.

Start with the [CLI quick reference](/cli/quick-reference/) for task-oriented
examples covering authentication, objects, Markdown, files, chats, backups,
and MCP clients.
