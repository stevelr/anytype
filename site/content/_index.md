## What `anyr` includes

- Structured JSON for automation and tables for interactive use
- Space, object, schema, file, chat, list, view, member, and sharing commands
- External Markdown editing and selective Markdown export
- Backup, restore, archive comparison, and terminal inspection
- A bounded, workflow-oriented Model Context Protocol server
